Before registering

  • Confirm the device supports secure remote integration.
  • Install all available firmware updates.
  • Change manufacturer default passwords.
  • Enable multi-factor authentication with the provider when available.
  • Inform affected tenants about device data collection.

Initial device status

New devices are registered with a Pending status. They should only become active after the provider connection has been securely verified.

Never enter device secrets

Do not enter passwords, door codes, alarm PINs, API keys, access tokens or recovery codes into this form.

Privacy information

Cameras, locks, occupancy sensors and similar devices may process personal information. Confirm the applicable privacy and tenancy requirements before installation.
