Smart Property AI evaluation reports

This directory stores JSON reports generated by ai/evaluate.py.

Generate a report

Validate the configuration without loading a model:

python -m ai.evaluate `
  --model-id smart-property-ai-v1 `
  --test-file ai/datasets/processed/test.jsonl `
  --dry-run

Run the complete evaluation:

python -m ai.evaluate `
  --model-id smart-property-ai-v1 `
  --test-file ai/datasets/processed/test.jsonl

Update the registered model's metrics after evaluation:

python -m ai.evaluate `
  --model-id smart-property-ai-v1 `
  --test-file ai/datasets/processed/test.jsonl `
  --update-registry

Report contents

Each generated report can contain:

model ID and evaluation timestamp;

number of evaluated examples and languages;

evaluation loss and perplexity;

exact-match and token-F1 scores;

response-length ratio;

sensitive-output warning rate;

prompts, expected answers, and generated answers;

limitations requiring human review.

Privacy and security

Use synthetic, licensed, or properly anonymized test data.

Never include tenant names, addresses, payment details, identification
numbers, authentication tokens, private complaints, or other personal data.

Treat generated JSON reports as internal development artifacts.

Review flagged output before deploying a model.

Do not rely on automatic metrics alone for legal, financial, safety, or
tenancy decisions.

Generated JSON reports are excluded from Git by the accompanying .gitignore.
If a report is approved for publication, remove sensitive examples and commit
only the sanitized report intentionally.
